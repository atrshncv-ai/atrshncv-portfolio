# Интерфейсы и общие правила

## Границы, решённые в спецификации

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `Hero` | аудитория, предложение, CTA | якоря `#projects`, `#contact` | визуальное оформление первого экрана |
| `Projects` | кейсы, их порядок и визуализация потоков | `id="projects"`, внешние ссылки | разметку карточек и графику pipeline |
| `About` | короткое объяснение специализации | `id="about"` | текст и компоновку блока |
| `Process` | этапы внедрения под ключ | `id="process"` | оформление этапов |
| `Skills` | технологии, связанные с задачей и кейсами | `id="skills"` | группировку стека |
| `Experience` | рабочая хронология без дублирования кейсов | `id="experience"` | внутреннюю модель записей |
| `Contact` | статический запрос, Telegram и email | `id="contact"`, mailto/Telegram URL | сбор полей и формирование черновика |

## Общие правила проекта

- Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4; lockfile — `package-lock.json`.
- Статическая сборка: `npm run build`, результат — `out/`. Публичный путь сайта — `/atrshncv-portfolio/`; для файлов из `public/` использовать `publicAssetPath`.
- Не добавлять серверный runtime/API. Существующие контакты остаются mailto, Telegram и email.
- Автотестов в проекте нет; тестовый набор не добавлять и не запускать. Проверить статическую сборку и вручную осмотреть локальную страницу.
- OpenCode исполняет только задачи с тикетами; этот T0 проход выполняется целиком в одном контексте по Autopilot.
