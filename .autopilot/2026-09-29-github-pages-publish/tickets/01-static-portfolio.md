## Что должно заработать

Существующее русскоязычное портфолио собирается как набор статических файлов для GitHub Pages. Его чат-панель и форма связи предлагают Telegram и email без серверной отправки и без ложного сообщения об успехе.

> «превратить в сайт»
> «Оставить Pages бесплатным; чат и форма ведут в Telegram/email»

## Критерии приёмки

- [x] Production-сборка выдаёт статический сайт в `out/` без сервера для показа страницы.
- [x] HTML, стили, скрипты и изображения работают по адресу репозитория с префиксом `/atrshncv-portfolio/`.
- [x] Главная страница сохраняет текущие секции, тексты, кейсы, изображения и оформление.
- [x] Панель чата даёт рабочие Telegram/email-ссылки и не запрашивает прежний `/api/chat`.
- [x] Форма открывает email-черновик с введёнными полями; Telegram доступен как прямой канал; интерфейс ясно говорит, что письмо отправляется почтовым приложением посетителя.
- [x] Удалены или исключены из статической сборки серверные API-обработчики, которые требовали хостинга Node.js.
- [x] Не добавлены и не запущены автоматизированные тесты; production-сборка выполняется имеющимися зависимостями.
