# atrshncv-portfolio

Персональное русскоязычное портфолио Александра Трищенкова — специалиста по AI-автоматизации.

## Технологии и структура

- Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4; зависимости фиксируются в `package-lock.json`.
- Страница и metadata: `src/app/page.tsx`, `src/app/layout.tsx`; секции портфолио: `src/components/portfolio/`; публичные файлы: `public/`.
- Путь к статическим файлам проекта обрабатывает `src/lib/public-path.ts` (`publicAssetPath`). Используй его для ссылок на файлы из `public/`.
- GitHub Actions workflow: `.github/workflows/deploy-pages.yml`.

## Проверенные команды

- `npm ci` — зависимости установлены успешно.
- `npm run build` — успешная статическая сборка; результат находится в `out/`.

## Подводные камни

- GitHub Pages для этого репозитория обслуживает сайт по базовому пути `/atrshncv-portfolio/`; конфигурация находится в `next.config.ts`. Сохраняй этот префикс у ресурсов и ссылок.
- Сайт экспортируется статически в `out/`; серверные API и серверный runtime на Pages не работают.
- Шрифты Geist и Geist Mono подключены через `next/font/google` в `src/app/layout.tsx`. Сборка скачивает их из Google Fonts, поэтому ей нужен сетевой доступ к Google Fonts.
- Форма контактов открывает заполненный черновик через `mailto:`; пользователь отправляет письмо из своего почтового приложения. Быстрые способы связи — Telegram и email, заданные в `src/components/portfolio/Contact.tsx`.
- Workflow собирает `out/` при push в `main` или ручном запуске. В настройках репозитория источником GitHub Pages должен быть выбран GitHub Actions. Workflow подготовлен, но коммиты этой работы ещё не отправлены и публикация не подтверждена.

## Сборка и разработка

- Установить зависимости: `npm ci`.
- Собрать статический сайт: `npm run build`.
- Локальный режим разработки: `npm run dev` (скрипт определён в `package.json`).
- Автоматизированные тесты не добавлять и не запускать.

Работа ведётся навыком `/autopilot`. Требования, спецификация и таски находятся в `.autopilot/`.
